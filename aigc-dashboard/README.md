# AIGC 互动大屏 · 运营后台看板

面向运营人员的单页看板：展示多台 AIGC 互动大屏的**参与人数、生成成功率、扫码/分享转化、平均生成时长、内容审核、设备在线状态**，支持按**日期与点位**筛选，并提供**规则预警**与**异常事件**两条排查线索。

数据全部为模拟数据，与任何真实业务无关。

## 运行

**方式一（推荐）：直接双击 `index.html`**
不需要装任何东西。ECharts 在 `vendor/` 本地引入，数据通过 `data/mock.js` 以 `<script>` 加载，全程不访问外网。

**方式二：起一个本地静态服务**
```bash
npx serve .          # 或 python3 -m http.server 8000
```

## 目录

```
index.html                    看板本体（结构 + 样式 + 逻辑，单文件）
vendor/echarts.min.js         ECharts 6.1.0，本地引入
data/generate_mock.py         模拟数据生成器（随机种子 42，可复现）
data/mock.json                模拟数据（交付物）
data/mock.js                  同一份数据，供 file:// 直接打开时读取
data/hll.py                   HyperLogLog 实现（与 index.html 里的 JS 版逐位一致）
docs/*.template.md            文档模板，阈值等数字用 {{占位符}} 从 mock.json 注入
docs/指标说明.md / .pdf        指标定义、计算口径、对应的运营动作（PDF 一页）
docs/AI工具使用说明.md / .pdf  使用的工具、关键提示词、对抗性评审与本人修改
docs/修订说明.md / .pdf        外部评审提出的六条问题、改法与验证方式
scripts/build_docs.py         模板 → 文档（阈值单一来源）
scripts/build_pdf.mjs         Markdown → PDF
scripts/verify.sh             一条命令跑完全部校验（60 项断言）
scripts/verify_metrics.py     独立重算全部指标，不经过前端
scripts/verify_render.mjs     无头浏览器比对页面 DOM 与独立计算
scripts/package.sh            打包成提交用的 zip
```

重新生成数据与文档（结果完全一致）：
```bash
python3 data/generate_mock.py     # 数据（种子 42）
python3 scripts/build_docs.py     # 模板 → 文档，阈值从数据注入
node scripts/build_pdf.mjs        # 文档 → PDF
bash  scripts/verify.sh           # 全部校验，60 项断言
```

## 看板包含什么

| 区块 | 内容 |
|---|---|
| 筛选行 | 日期快捷范围 + 自定义起止、城市、点位多选；作用于整页所有内容 |
| KPI 磁贴 | 6 个核心指标，各带环比和迷你趋势线；越过阈值时高亮并标注文字说明。参与人数主显跨期去重估算，副标题给人次与人均次数 |
| 规则预警 | 按阈值实时扫描当前切片；区分「区间合计」与「最近一天」，后者标记为“仍在发生” |
| 图表 | 参与与转化趋势、生成成功率趋势、平均生成时长趋势、内容审核构成、点位对比、五段转化漏斗、高峰时段分布 |
| 设备状态 | 8 个点位的在线/降级/离线、最后心跳、当日成功率与时长 |
| 异常事件 | 可按级别/类型/状态筛选，点击展开建议处理动作 |

## 几个实现上的取舍

- **P95 存的是直方图不是数值**。分位数无法像均值那样加权聚合，每条记录存 14 档生成时长分布，跨切片时先合并直方图再线性插值，保证任意筛选组合下 P95 都算得准。
- **平均生成时长只统计成功生成**。失败多为超时，计入会系统性拉高均值。
- **告警按连续区间去重**。一次持续异常只开一张单并记录起止日期与持续天数，而不是每天刷一条。
- **不使用双轴图**。两个量纲不同的指标一律拆成两张图，避免用坐标轴的对齐方式编造出数据里没有的相关性。
- **颜色不单独承担含义**。状态一律配文字标签，每张图都提供表格视图。

- **文档里的阈值不手写**。`docs/*.template.md` 用占位符，由 `scripts/build_docs.py` 从 `mock.json` 的 `meta` 注入，改配置文档会跟着变。

指标口径详见 [`docs/指标说明.md`](docs/指标说明.md)；外部评审提出的问题与改法见 [`docs/修订说明.md`](docs/修订说明.md)。
