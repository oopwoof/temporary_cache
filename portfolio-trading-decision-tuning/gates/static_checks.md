# 静态核验检查项（G1）

`python3 scripts/lint_skill.py skills/current/SKILL.md` 覆盖其中大部分；标 ✋ 的需另写规则或人工。

## 红项（一票否决，不可豁免）

| # | 检查 | 判据 |
|---|---|---|
| R1 | 题面数值泄露 | SKILL.md 与 reference 中出现各题的任一具体数值（含小数／≥4 位整数／带单位非通用数） |
| R2 | 题面专有名词泄露 | 出现题面公司名、系统名、编号、人物代号 |
| R3 | 对照组原句泄露 | 与对照组 response 归一化后连续 15 字重合 |
| R4 | ✋题目级规则进主文件 | 一条规则对该模式不足半数合理请求适用（脚本只出候选，卡 6 人工终审） |

R1–R3 由 `lint_skill.py` 自动判红，需同时给 `--cases-dir` 与 `--responses-dir`。
**没给参数时该项记 SKIPPED，SKIPPED 不等于通过**，卡 4 上单独显示。

## 黄项（带理由可放行，记入卡 4）

| # | 检查 | 阈值 |
|---|---|---|
| Y1 | 禁令缺替代路径 | 0 处 |
| Y2 | 重复约束 | 0 组 |
| Y3 | 自检项数 | ≤12 |
| Y4 | 加粗占正文比 | ≤1/3 |
| Y5 | 标为必读的 reference 数 | ≤2 |
| Y6 | 各档必备件最小字数和 | <该档硬上限的 60% |
| Y7 | 规范面/检查面对齐 | 自检提到的检查点，规范段有对应条款 |

Y6 来自实证：某版 direct 档只剩 31 字符余量。Y7 来自实证：某版把「含表格单元格」只写进自检、没写进规范面。

## 输出
`runs/<n>/静态核验.md`：逐项结果 + 红黄绿汇总 + 命中原文位置。
`--json runs/<n>/静态核验.json` 供卡 4 渲染与金标准回归（`scripts/selftest.sh`）。

退出码：0 全绿 / 1 有黄项 / 2 有红项。红项不可豁免，CI 里直接拦。

**所有命中只作"候选"，判分项回原文人工确认——本项目已发生四次正则误判。**
