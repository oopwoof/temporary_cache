# 角色 06｜Release（阶段 5，Orange）

## 输入
全部产物、`never_regress` 清单、判分回填、`gates/acceptance.yaml`

## G3 回归核验（先于看胜负）
逐条过 `packs/<skill>.yaml` 的 `never_regress`。**任一回退即判本版有缺陷，不因总分上升而放过**，自动回退上一版。

## 判分质量核查（先于 G4，读数不合格就不要往下算）

```bash
python3 scripts/check_judge_quality.py --pack runs/<n>/g0_pack \
    --keys runs/<n>/_answer_key/g0_keys.json \
    [--shard-map runs/<n>/g0_pack/调度清单.json] --out runs/<n>/判分质量.md
```

六查：原句 ≥10 字且能在原文逐字找到、排序与分数自洽、跨题重复原句、
**字段使用率**、**三轮独立性**、**跨片尺度漂移**。

- **退出码 2（硬不合格）**：缺 ranking、原句查无此句、三轮分数完全相同 →
  这批读数不要进 G4，先查回收与判分过程
- **退出码 1（告警）**：`hard_gate_hits` / `technical_failure` 全程 0 次，
  **当成异常去查**，不要当成「没有问题」——48 个题次里它一次都没记过，
  其中一份「承诺 35 件交付物、实际 0 件」的答复还拿了四方最高分
- 判分方确实漏用字段时，调优侧可按纪律包自行改判，但必须：两个读数并排列出、
  写明哪个是自己改的、**自行改判只能往对自己不利的方向做**

## G4 准出判据（2026-09-14 起的规定口径，不可改）

盲评是 **1-5 分打分**，不是排序。

1. **对豆包裸模（三条全过）**：均分差 ≥0.4｜对裸模胜率 >60%｜8 题**至少 6 题超过**（平局算没超过）
2. **对 WorkBuddy（二选一）**：胜率 >60%；或**对裸模分差 >0.5 且对 WB 胜率 ≥50%**

两条路径须在**同一轮内同时**满足。
**多轮判定里只需要有一次满足即可**（需求方 2026-09-15）。

```bash
python3 scripts/score_release.py --run runs/<n> --thresholds gates/thresholds.yaml \
    --candidate ours --per-pass --out runs/<n>/准出核算.md
```

**`--per-pass` 必须给。** 不给就是先把各轮平均再核，会把达标的那一轮抹平
（实测：三轮 −0.125 / +0.875 / −1.500，平均后不达标，逐轮核则达标）。

旧的排序型判据（四方第一名数 ≥7）**已作废**，不要再用。

## 达标之后还要继续迭代

需求方 2026-09-15：**即便某一版已经达标，迭代仍然往表现更好的方向做。**
达标不是终点，是这一版可以交付。

内部看进步用「三轮里达标的轮数」（1/3 → 2/3 → 3/3）比看「达没达标」灵敏得多——
**但这个指标只进内部报告，不进交付报告。**

## 两份报告，分清楚

### 交付报告（给需求方）—— 只报规定标准

需求方 2026-09-15：**交付时只需汇报复核规定标准即可。**

只写这些：

| 段 | 内容 |
|---|---|
| 结论 | 达标 / 未达标，以及是哪一轮达标 |
| 逐条复核 | 两条路径的每一条，要求值 vs 实测值，逐条打勾 |
| 逐题分数 | 候选与各对照方的 1-5 分 |
| 版本与校验 | 交付的 skill 包版本、目录内容摘要 |
| 事实边界 | 测的是哪个版本、几轮、哪一轮达标——**只陈述事实，不做方法学评论** |

**不写**：噪声底分析、judge 偏差、一致率、rubric 覆盖率、对判据本身的建议。
这些都留在内部报告。**如实不等于把所有内部过程倒给需求方**——
边界该写的是「这个数是怎么来的」，不是「我认为这个判据有问题」。

### 内部报告（留在实例里）—— 方法学都在这

`判分质量.md`、`归因表.md`、`人审卡.md`、覆盖核验、噪声底、对判据的改进建议。
**有话直说，不粉饰**：门禁没过就说没过，没测的写未测，自己引入的回退主动说。

## 上游反哺
生成器缺陷（题面数值写成通用规则、禁止正确解法方向、reference 与主文件冲突）单独三句报产品侧。批量之后做跨 skill 统计——「N 个 skill 里有 M 个同类缺陷」比单案例有力得多。

## 结束动作
产出卡 6 + 交付报告。**卡 6 是唯一永不撤销的人工确认点。**
