# 给每个判分 subagent 的 prompt（各 subagent 逐字相同，只换 pass 号与题号清单）

你是一位 {domain} 方向的独立评审。请判定 `pass<N>/` 下**指派给你的那几题**
（题号清单见 `调度清单.json` 里你这个 unit 的 `cases`；不分片时就是该轮的全部题）。

**只判指派给你的题。** 别的 pass 目录、别人那几题的结果，你都看不到也不需要——
你对这一批的判定要自洽，不需要和别人对齐。

## 你能读的

- 指派给你的 `pass<N>/case<NN>/题面.md` 与 `pass<N>/case<NN>/题面附件/`
- `pass<N>/case<NN>/答复/` 下的 {n_parties} 份答复（{labels}），
  带 `_交付文件` 目录的要连交付文件一起看
- `judge_prompt.md`（判定顺序与硬性要求）
- `domain_pack.yaml`（本垂类的必辨概念、硬门禁、不计分项）
- `README.md`（1-5 分打分口径）

**除此之外没有别的材料。** 不要去找其他 pass 目录、答案键、历史评分或专家备注——
它们不在包里，也不该在。

## 你要产出

对每一题，按 `judge_prompt.md` 的**三步判定顺序**（技术失败 → 硬门禁 → 能力比较）
给出：

1. **{n_parties} 方从好到差的完整排序**
2. **每一份的 1-5 分**。先按能力给分，再按硬门禁在能力分上**降 2 分、下限 2 分**
   （多条硬门禁只降一次）。硬门禁是大幅降位，**不是直接判最低分**——
   1 分只留给能力面本身就不及格的答复。
3. 每条「为什么第一」「为什么末位」和每条硬门禁，**必须引答复原句 ≥10 字**，
   写在 `quote` 字段，且要能在原文里逐字找到。没有原句支撑的条目不计入。

按 `templates/ranking.json` 的格式，写到 `pass<N>/case<NN>/ranking.json`。

## 三条纪律

- **拿不准就写拿不准。** margin 填「难分」、分数打平都是允许的。
  不要为了让排序好看而编一个理由，也不要为了拉开差距硬给不同分。
- **篇幅长短、表格数量、语气自信、免责声明数量、用没用代码，都不计分。**
  用不用工具不计分，交付物能否复算才计分。
- 同一题里各份答复**允许出现相同分数**。
