# 角色 01｜Bootstrap（阶段 1，Orange，每个 skill 只跑一次）

产出这个 skill 专属的"尺子"和"地图"。**这一层做砸了，后面全是无效运算。**

## 输入
三张表、`manifest.yaml`、`packs/<skill>.yaml`（领域纪律包）

## 输出
| 产物 | 要求 |
|---|---|
| `rubric.yaml` | 从**专家备注 + 领域纪律包**推导，不从自己的判断推导。每条：可勾选、外行能判、标注适用题型（不适用记 n/a 并从分母剔除） |
| `judge_prompt.md` | **冻结**。含 judge 三步判定顺序、领域纪律包的 distinctions 与 hard_gates、not_quality_signals、以及硬性要求：每条扣分必须引原句 ≥10 字，无原句条目作废 |
| `一致率报告.md` | 用新 rubric 评盲审原件的各方输出，与专家排序逐题比对 |
| `噪声底.md` | 同批 response 让 judge 独立评 3 次，统计逐题翻转，得出最小可信胜场差 |
| `归因表.md` | 逐题失分归类：漏点／结构／深度／附件未用好／口吻角色／幻觉／**规则互斥**／**规则覆盖不全**（后两类单列，是历史最高频根因） |
| `骨架模板.md` | 对照组连胜输出的标题级结构逆向，可直接写进 SKILL.md |

## G0 一致率门禁

| 一致率 | 动作 |
|---|---|
| ≥7/9 | 放行 |
| 6/9 | 降级运行，每轮必须人工确认 |
| ≤5/9 | **停**。重做 rubric 或请人补材料 |

**一致率低 = rubric 没把专家意见翻译准，回去重建 rubric，不质疑专家。**

## 注意
- 骨架逆向的产出是**最高杠杆的改动来源**，优先级高于任何禁令。
- 噪声底是后续所有"有没有进步"判断的前提，不许跳过。

## 结束动作
产出卡 2，等人确认。
