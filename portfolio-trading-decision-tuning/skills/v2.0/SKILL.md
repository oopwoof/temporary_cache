# 持仓交易决策

仅用本次请求、附件和本轮明确取得的数据。不连接券商、不代下单、不索取凭证、不声称已执行、不保证回本或收益。

计算口径见 `references/calculation-contract.md`；Excel 交付见 `references/excel-contract.md`；转出见 `references/routing.md`。

## 四个前置硬门

1. **缺输入先提问**：缺现价、汇率、费用、总资产口径、可卖数量、期限或风险上限时，最终回复必须直接用普通文本列出待补信息并给条件框架；禁止调用 `AskUserQuestion` 等不存在的工具，禁止补造行情、均线、MACD、RSI、成交量、来源或图表。现价与历史序列只能来自材料；派生指标（均线、波动率等）只能用材料内序列计算并写明样本区间；禁止标注材料中不存在的数据来源（如"Wind/交易所 X 年 X 月 X 日收盘"）。
2. **if→then 必须有正文**：每条规则必须实际写出条件、动作、确定数量/比例或取整公式、执行时点和复核项。只有标题或 R0/R1 名称视为未完成，不得提交。条件不成立（停牌、涨跌停、零买盘、部分成交、报价失效）时，成交数量和现金记 0，不得把委托写成已完成。禁止“确定/确保/一定成交”。批准或执行规则须再次写明：截止前报价仍有效、可卖量仍有效。
3. **Excel 必须验算**：若用户要求可复算 Excel，必须真实创建并在交付前重算；扫描 `#REF!/#VALUE!/#DIV/0!/#N/A`，抽查关键引用与正文数字一致。无法验证时明确降级，不得声称交付成功。
4. **交付前自检**：最终回复是给客户的成品。清除全部内部思考、自我纠错痕迹（"等等/让我算一下/我需要修正"）和重复标题；每个数字可溯源到材料或本回复内的计算步骤，禁止无来源数字；正文、表格、CSV/Excel 对同一指标同公式同数值。

## 勾稽与约束

冻结 `as-of`、时区、基准币种、报价、现金/可取资金、数量/可卖数量、批次成本、费用税费、结算、期限和风险预算。先勾稽现金+市值+应收应付与总资产；冲突并列明细锚和报表锚情景，不填造其他资产。

**批次台账**：可卖数量按批次逐笔建账（批次、成本、解冻/可卖起始日、可卖量），各批次加总必须等于材料给出的可卖总量，并与正文表格、附注交叉一致后才进入情景测算。声明的卖出顺序（如 C→B→A）严格执行；被保护批次只在穷尽其余批次仍不足时才动用，并写明这是对偏好的偏离。对照情景（如"完全保留某批次"）与主方案共用同一台账、同一费用口径。

**日历与时刻**：每个关键日期核对星期和是否为交易日/资金可用日；截止日落在周末或节假日时，写清实际最后行动日，禁止把非交易日写成可执行日或资金备妥截止日。"当前可执行"须核对当前时刻是否在交易时段内；已收盘或非交易日时改写"下一交易日可执行"，禁止把已收盘时段的数量标为当下可执行。

区分账面数量、券商可卖、T+1复核可卖和当下可执行。停牌、涨跌停、整手、结算和流动性优先于用户偏好。跨币种仅用已提供汇率，晚到汇率不参与。

## 求解顺序

1. 列出全部硬约束，标出当前最紧的一条；主方案必须把最紧约束反解到可执行整手数量。次严约束先过线，不得当成风险已解决。
2. 用户偏好与合规方案必须分开算。冻结被保护持仓后，在今日可卖范围内穷尽其余标的，再输出：仍超限的绑定约束 / 已被其他卖出消掉的约束。禁止把未调整方案的红灯集合复制到偏好方案，也禁止把已能压回的约束一并要求放宽。
3. 主路径数字必须标明成交假设。若首选标的无法成交，须当场反解一条不依赖该笔成交、仍满足硬约束的后手；未成交仓位不得写入“已合规”。
4. 诊断表、排序表、正文对同一指标只用一套公式、一套数；占比类指标须能加总核验。冲突则降级，不得继续往下排减仓。任何"保留某批次/不卖某标的"的对照情景，用与主方案相同的批次台账重算持仓与集中度，不得沿用未调整口径。

## 计算与动作

补仓、减仓、提款方案都要列交易前后：成交额、费用、净回笼、实现盈亏、剩余成本、现金、总资产、单票/前三大权重、可卖余量和硬约束。最少整手数量必须验证相邻一手。

**费用勾稽**：每笔费用总额=佣金+过户费+印花税+题内滑点之和，隐含费率（费用/成交额）对照题设费率表核验；净回笼=成交额−费用总额；实现盈亏统一为扣费后口径，正文与 CSV/Excel 同值。盈亏/损失全文同一符号约定，跨情景不变号。

**尾部风险指标**（VaR/CVaR 等）显式写出分位样本数 m 的公式与取值；题面给定公式（如 m=ceil((1−置信度)×N)）时严格按题面执行并披露 m 与样本数，不自作改用替代口径。

**随附脚本**输入输出用相对路径或命令行参数，禁止硬编码本机绝对路径；交付前实际运行一遍，抽查产出与正文一致。

统一格式：

```text
If [可观察阈值 + 截止时点]
→ Then [下一可执行时点的动作；数量=明确数值或 ceil/floor 公式；目标权重；费用；交易后复核]
```

移动基准使用方案开始后的历史最高完整收盘价，只上移不下调，触发减仓后也不重置。覆盖跳空、停牌、无法成交、报价变化、到账延迟和计划第10日/截止日的到期复核。

提款先满足到账日、可划转金额和结算。材料表述为"备妥/准备/预留"资金时，默认资金仍在账内，禁止默认已划出：主口径风险与权重用"交易后、资金仍在账内（已备妥可划转）"的净资产；"假设已划出"只作敏感性附录，未穷尽只卖当下可执行标的的整手网格前不得写无解。卖 ETF 只能补现金缺口，不能解决股票权重超限；单股超限必须减对应股票或明确无法合规。

## 输出结构

- 已知/缺失输入与双口径勾稽
- 硬约束清单（含最紧约束）及用户偏好方案与合规方案对比
- 可执行整手、费用、净回笼、权重和压力预算（主路径注明成交假设；不成交后手单列）
- 完整 if→then 时间线及最迟行动日（行动日须为材料中的交易日或资金可用日，不编造材料外日期）
- 下单前复核清单、交付前自检确认（无内部思考残留、数字可溯源、跨文件一致）与非执行声明

封闭材料题不搜索。确需公开数据时优先 `seed_finance_search`，基金/大宗覆盖不足才用 `general_search` 定向官方来源并标注降级。
