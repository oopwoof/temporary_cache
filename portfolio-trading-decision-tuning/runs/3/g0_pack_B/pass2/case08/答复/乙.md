## 一、结论先行

• 当前S01市值879,200元、账户总资产1,029,200元，单一证券权重85.4256%，明显高于60%上限。总持仓成本712,000元，账面浮盈167,200元，收益率23.4831%。

• 两笔教育费用合计220,000元，支付后还需保留80,000元现金，故从现有150,000元现金之外至少需要形成150,000元税费后卖出净收入。按31.40元估算，仅为现金目标最少卖4,800股，但这样在两笔支出后单一证券权重仍约90.0381%，不能满足60%约束。

• 现金目标与集中度共同约束下，正常区间应按较保守的29.80元测算，累计卖出至少12,700股；若按当前31.40元测算，12,600股已可满足，但12,700股可覆盖29.80元下沿。该结果意味着至少需要动用部分低成本批次A，客户希望保留全部12,000股A的偏好与hard风险限额冲突。

• 若连续两个交易日收盘低于27.50元，按情景价26.80元，五个交易日内需累计卖出至少14,600股，才能在当时把单一证券占比降至40%以下；按日均可成交3,000股估计，需3,000+3,000+3,000+3,000+2,600，刚好占满五日，不能保证实现。

• 推荐采用“先修当前60%，再锁定11月15日后60%”的两阶段安排；如价格回升至33.60元以上则缩短执行周期，如跌破风险线则切换40%应急方案。所有股数是条件成立后的计划，不代表已成交。

## 六、建议的分阶段安排

阶段1：尽快修复“当前60%”并预留现金。

• If 获得客户授权、券商显示可卖数量不低于6,000股，且价格处于29.80–33.60元、有效买盘支持日估计6,000股，then 第一日计划卖出6,000股；内部优先归因于批次C的旧6,000股。按31.40元估算净收入188,249.28元，卖后总股数22,000股，但当前权重仍约67.13%，因此只是第一步。

• If 下一交易日确认批次C当日买入2,000股已转为可卖，且正常区间仍成立，then 再卖2,600股，使累计卖量8,600股；内部归因为C 2,000+B未质押600。按31.40元估算两日累计净收入269,823.97元，当前单一证券权重降至约59.20%。If 可卖状态未更新，then 不卖该2,000股，改用其他已确认可卖股数并重新核对批次偏好。

阶段2：在付款前锁定“11月15日支付后仍≤60%”。

• If 价格仍在29.80–33.60元且累计只卖8,600股，then 最迟在第一笔付款前的预留窗口再卖4,100股，使累计12,700股；内部归因为B剩余1,400+A 2,700，最终预计A保留9,300股、B质押6,000股，总持股15,300股。实际现金可划转时点必须由券商确认。

• If 价格达到或高于33.60元并有参考34.00元附近的有效成交，then 将总目标调整为12,500股，受客户单日6,000股约束分为6,000+6,000+500；不得因上涨取消集中度整改，也不得把34元写成保证成交价。

阶段3：风险线应急。

• If 连续两个交易日收盘价低于27.50元，then 从第二个确认收盘后的下一可交易时段起，在五个交易日内按实际可卖与买盘安排3,000+3,000+3,000+3,000+2,600股，累计目标14,600股；内部归因C 8,000+B未质押2,000+A 4,600，预计A剩7,400、质押B剩6,000。

• If 任一日仅部分成交或零成交，then 只累计实际成交数量，不得把剩余委托当成已降仓；立即重算剩余天数与日均所需量。若剩余需求超过3,000股/日估计上限，应向客户经理报告“40%时限存在不可执行风险”，而不是声称止损已完成。

## 七、完整if→then交易纪律

| 规则 | if 条件 | then 动作 | 失效/复核 |
| --- | --- | --- | --- |
| R1 可卖核验 | 券商总持仓28,000且正式可卖≥20,000 | 交易数量只能来自已确认可卖；当日新买2,000和质押6,000均排除 | 每笔委托前复核 |
| R2 正常区间首段 | 29.80≤有效价≤33.60且买盘支持 | 单日最多卖6,000；首日目标6,000 | 未授权、买盘不足或部分成交即按实际回报 |
| R3 当前60% | 累计卖6,000后次日仍在正常区间 | 补卖2,600至累计8,600，使当前权重≤60%留小幅缓冲 | 实际价变化后重算，不能照搬 |
| R4 付款后60% | 累计卖量<12,700且29.80下沿仍适用 | 再卖至累计12,700，并在付款前确认现金可划转 | 如价格≥33.60可按R6重算12500 |
| R5 跌破支撑 | 收盘<29.80但尚未连续两日<27.50 | 按29.20情景累计卖12,700，日量最多4,000 | 价格、买盘或可卖数变化即复核 |
| R6 价格回升 | 有效价≥33.60，参考34.00且有买盘 | 累计卖12,500，单日仍不超过客户上限6,000 | 跌回33.60下方则回到S01 |
| R7 风险线 | 连续两日收盘<27.50 | 五日内目标累计14,600，日计划3,000×4+2,600 | 部分成交只记实际；剩余需求/天数超3,000即报告不可行 |
| R8 质押 | 11月30日前或解除登记未确认 | 质押6,000股可执行量始终记0 | 只有正式解除并更新可卖后才改变 |
| R9 现金 | 税费后累计净收入<150,000或现金不可划转 | 不得认定教育资金已备妥；补足净额并确认可划转状态 | 券商正式资金状态更新 |
| R10 停止条件 | 累计卖量达到对应情景目标且双重比例/现金均满足 | 停止额外卖出，复核剩余A偏好与事件风险 | 新价格或支出计划变化 |

## 八、批次偏好、费用和损益权衡

若按“优先保留低成本A”归因，正常保守方案12,700股的出售构成为C 8,000+B未质押2,000+A 2,700，最终A仅能保留9,300股；34元回升方案出售C 8,000+B 2,000+A 2,500，A可保留9,500股；26.80元风险线方案需出售C 8,000+B 2,000+A 4,600，A仅保留7,400股。

实现盈亏会随价格变化：正常区间下沿29.80元出售12,700股，按上述归因和费用估算实现收益约1,017.23元；29.20元约实现亏损6,596.67元；34.00元约实现收益51,160.00元；26.80元出售14,600股约实现亏损20,753.02元。客户“少实现亏损”是soft偏好，不能覆盖现金和集中度hard。

如果只追求少实现亏损，可以优先卖出有浮盈的A/B，但会更明显违背保留A的偏好；如果只追求保留A，则优先卖C会确认亏损。两者不能同时最优，建议客户经理在hard约束已经锁定的总卖量内，让客户明确偏好排序。

## 九、当前不可执行和待确认事项

• 不可把B质押6,000股用于10月30日、11月15日付款或风险线五日计划；11月30日仅可申请解除。

• 不可在8月26日卖出C当日买入2,000股；下一交易日也需看券商可卖状态。

• 不可把情景日均可成交量视为保证；客户单日6,000股上限与情景量取较小者。

• 资金结算、可划转时点和银行端支付安排未提供，必须向券商确认；在确认前只能说“预计净收入”，不能说“已备妥现金”。

• 需确认券商是否支持批次层面的成本指定；如不支持，批次保留仅作经济归因。

• 若未来支出金额、日期、质押状态、可卖数量或账户现金发生变化，所有数量和比例必须重算。

## 十、授权与沟通用语

本备忘录建议客户经理使用“如果条件成立，则计划……”的表达。不得使用“已经卖出”“保证在某价成交”“一定能止损”“一定能保留收益”等措辞。所有比例基于附件的情景价格和账户结构，真实成交前必须取得客户授权，成交后必须用实际数量、实际费用和最新账户总资产重新核验。

## 附：核心计算公式

税费后卖出净收入 = 成交股数×成交价 − max(5元, 成交额×0.03%) − 成交额×0.05%。

支付后现金 = 150,000 + 税费后累计卖出净收入 − 120,000 − 100,000。

支付后单一证券权重 = 剩余股数×情景价 ÷ [28,000×情景价 +150,000 − 交易费用 −220,000]。
