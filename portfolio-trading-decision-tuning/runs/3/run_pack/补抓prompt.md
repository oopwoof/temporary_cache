# 补抓 prompt（占位形态时照抄，不要改措辞）

> 用于：平台回了「已委派…后台执行中」之类的占位，终稿还没出来。
> **补抓不是重跑**，首次有效生成仍算那一次。

```
回到 case<NN> 那个会话，**只读取、只下载，不要发任何消息**。
（包括「完成了吗」「请给我文件」——一发消息这题就变成多轮对话，
与其余题不是同一个条件，那一题的读数作废。）

请回报四件事：
1. 页面当前是终稿还是仍停在占位
2. 正文：原样复制，过程独白、报错、截断都不要删
3. 交付件：**页面可见几件** 与 **实际下载成功几件** 分开报
   （只在本机沙箱可见 = 抓不到；页面确实没有 = 没有。判分时不是一回事）
4. 若终稿只有发消息才拿得到：**停下**，如实写「需发消息才能取得，未取」
```

等待不算重跑，建议满 4 小时再去看。最终仍停在占位的，按**技术失败**单列，不进能力比较。
