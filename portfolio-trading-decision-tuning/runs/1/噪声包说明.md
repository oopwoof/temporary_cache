# 噪声底判分包说明｜runs/1/g0_pack_r2

## 一、这个包是干什么的

跑题第 2 轮（同一版本 v3.0、同一批题、原样重跑）一直没判，**模型侧噪声底至今是空的**。
没有它，「新版本比旧版本好」分不清是进步还是抖动——效应量必须和噪声底同表报。

## 二、设计：基线不动，只换 ours

这一包的**基线四方（base / base+skill / WB / gpt）与第一包逐字相同**，是同一批文件；
只有 ours 从第 1 轮换成第 2 轮。于是两包一比就能把噪声拆开：

| 量 | 怎么算 | 是什么 |
|---|---|---|
| 基线四方两包之差 | 同一份输入、重判一次 | **判分噪声** |
| ours 两包之差 | 输入变了（同版本重跑） | 判分噪声 + **模型噪声** |
| 两者相减 | — | ≈ 模型噪声 |

脚本已备好并用人造数据验过（基线不动 → 判分噪声 0.000；ours 全 +1 → 分解出 0.750）：

```bash
python3 scripts/noise_floor.py \
    --pack-a runs/1/g0_pack    --keys-a runs/1/_answer_key/g0_keys.json \
    --pack-b runs/1/g0_pack_r2 --keys-b runs/1/_answer_key/g0_keys_r2.json \
    --out runs/1/噪声底.md
```

**为什么这个分解重要**：准出的分差门槛是 0.4。如果判分噪声本身就有 0.2 以上，
那 0.4 的分差根本不足以证明版本变好——这正是「只报达标、不报噪声底」在高估结论。

## 三、顺带当一次三轮独立的彩排

runs/1 第一包的判分**三轮塌成了一轮**（`check_judge_quality.py` 退出码 2）。
runs/2 是决定性的一轮，**不适合再拿它试错**。这个包是补充性的、成本低，
正好用来验证判分方能不能做到真三轮独立：

- 若这包回来 `check_judge_quality.py` 仍是退出码 2 → 在 runs/2 判分**之前**就知道要换做法；
- 若这包通过 → runs/2 可以放心发。

## 四、发的时候要讲死的三条

1. **三轮由三个互不可见的会话各判一次，一次性同时发起**——不是判完一轮换个标签再映射一遍；
2. 三轮不共享上下文，不许跨 pass 比对或按文件哈希对齐洗牌映射；
3. **这一包要发给没看过第一包的会话。** 基线四方是同一批文件，见过第一包的会话会认出来，
   那就测不出判分噪声了。

## 六、回来之后

```bash

python3 <autotune>/scripts/check_judge_quality.py --pack runs/1/g0_pack_r2 \
    --keys runs/1/_answer_key/g0_keys_r2.json --out runs/1/判分质量_r2.md
# 2. 再跑噪声底分解（见第二节命令）
```

runs/2 的结论从一开始就要带着它报。
