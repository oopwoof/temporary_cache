### 7.2 做T约束与结论

1. **做T只能先卖可卖底仓，再回补≤已卖数量**，当日新买股份不得再次卖出。
2. 单日往返≤2,000股且≤ADV约束，日终持股不得高于日初。
3. **在权重和风险贡献双超限状态下，全额回补的做T不改善硬约束**。比较三种结果：
   - **不回补**：日终净减仓2,000股，权重下降约5.37pp，风险改善明确
   - **部分回补**（如回补1,000股）：日终净减仓1,000股，部分改善
   - **达到价差阈值后全额回补**：日终持仓不变，权重和风险贡献**无改善**，仅降低账面平均成本
4. 跌停、停牌、报价过期或无法确认回补价时，**不得假设做T完成**。
5. 先卖后价格上涨无法回补时，**这是做T失败情景，不是追加买入的理由**；未回补部分视为净减仓。
6. **做T不能替代为达到硬风险上限所需的净减仓**。即使做T成功获取价差收益，日终净持仓和硬约束状态不变（全额回补时）。

**建议**：做T仅作为净减仓计划的补充，在日内波动足够大时可尝试，但回补比例应受到"日终必须向减仓目标推进"的约束。在硬约束达标前，优先选择"不回补"或"部分回补"。

## 八、不可执行情景

| 情景 | 处理方式 | 后续动作 |
|---|---|---|
| 跌停无买盘 | 条件未成立，因此未执行；委托数量不计为成交或现金 | 次日集合竞价查看是否打开跌停；若打开则按当时价格优先补卖 |
| 停牌 | 条件未成立，因此未执行；停牌期间不得假设任何卖出 | 关注复牌公告；复牌后第一日重新评估价格和风险 |
| 复牌跳空下跌 | 按R-004（跌破偏好价）处理，硬约束优先 | 若可成交则加速减仓；若继续跌停则转回不可执行 |
| 价格跌破20.80元 | 软偏好不覆盖硬约束；通知客户后继续按计划卖出 | 记录客户反馈；若客户要求暂停且硬约束仍超限，记录冲突并升级 |
| 流动性恶化（买盘<计划量） | 当日卖出量=min(计划量, 买五档深度, 9000) | 剩余量顺延至下一交易日 |
| 客户未确认本金口径 | 不影响硬约束驱动的减仓计划；本金回收目标按多口径并列展示 | 尽快与客户确认口径后更新目标卖出量 |
